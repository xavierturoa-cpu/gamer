# Gamer — Neon Rush

A small, responsive arcade game built with plain HTML, CSS and JavaScript. It is designed to run directly as a GitHub Pages site with no server or build step.

## Play

- **WASD / Arrow keys:** move
- **Mobile:** drag your ship
- Collect cyan orbs to increase your score.
- Avoid the red hunters.
- Your best score is saved in the browser.

## GitHub Pages

Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Expected site: `https://xavierturoa-cpu.github.io/gamer/`
